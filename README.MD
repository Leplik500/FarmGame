## **Описание**
3D-фермерский симулятор на jMonkeyEngine с видом от третьего лица. Игрок выращивает растения, торгует в магазине и управляет экономикой фермы.

## **Основные механики**

- **Фермерство**: вспашка → посев семян → полив → рост → сбор урожая
- **Экономика**: продажа урожая и покупка семян в магазине
- **Цикл день/ночь**: днём работа, ночью сон в доме для ускорения времени
- **Автодвижение**: персонаж автоматически подходит к целям вне досягаемости
- **Сохранение**: полное состояние игры сохраняется в JSON

## **Управление**

| Действие       | Клавиша                | Примечание                  |
|----------------|------------------------|-----------------------------|
| Движение       | `WASD`                 | Двойной `W` = бег           |
| Взаимодействие | ЛКМ                    | Использование предмета/сбор |
| Инвентарь      | `1-9` / колесо мыши    | Выбор предмета              |
| Магазин        | ЛКМ по магазину (днём) | Торговля                    |
| Закрыть UI     | `X`                    | Выход из магазина           |
| Сон            | ЛКМ по дому (ночью)    | Пропуск ночи                |
| Сохранение     | `.`                    | Сохранить                   |
| Загрузка       | `,`                    | Загрузить                   |
| Камера         | `R` / `Ctrl`+колесо    | Сброс/зум                   |

## **Предметы**
- **Мотыга**: превращает траву в грядки
- **Лейка**: поливает сухие грядки (нужно для роста)
- **Семена**: тыква (5$) и помидор (3$)
- **Урожай**: тыква (20$), помидор (15$)

## **Проверочные сценарии**

1. **Базовый цикл**: вспахать → посеять → полить → дождаться роста → собрать
2. **Торговля**: продать урожай → купить семена
3. **Автодвижение**: кликнуть на далёкий объект
4. **Сохранение**: сохранить → перезапустить → загрузить
5. **День/ночь**: дождаться ночи → поспать в доме
